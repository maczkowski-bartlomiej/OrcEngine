# Unify Vertex and Untemplate Texturable

OrcEngine previously fragmented 2D quad geometry across distinct per-shape vertex structures (`SpriteVertex`, `RectangleVertex`, `CircleVertex`, `GlyphVertex`, `LineVertex`) and templated `Texturable<VertexType, VerticesCount>`, forcing per-field transcoding during dynamic batch submission in `Renderer`. We decided to untemplate `Texturable` into a non-templated `Transformable` base storing four `Vertex` elements directly, eliminate all legacy vertex structures, and have `Text` use `std::vector<Vertex>`. This enables zero-transcoding batch buffer copies into `Renderer`'s dynamic quad batcher, removes redundant template instantiation and dead vertex accessors, and establishes `Vertex` as the single canonical 2D batch vertex layout.
