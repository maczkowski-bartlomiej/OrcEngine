# Cross-Platform Preprocessor Standardization and Multi-Tier SDK Discovery

OrcEngine previously suffered from compiler-divergent macro expansion failures under GCC/Clang on Linux distributions due to legacy variadic comma suppression, along with brittle dependency and SDK lookup requiring manually exported environment variables. We decided to standardize all logging and assertion macros on the ISO C++20 `__VA_OPT__(,) __VA_ARGS__` expansion paired with MSVC's conforming `/Zc:preprocessor` flag, configure executable permissions for automation scripts in the git index, and expand CMake FMOD and vcpkg lookup with multi-tier fallback hints across standard Linux and Windows paths. This eliminates preprocessor syntax errors without argument workarounds, allows direct zero-configuration script invocation across distributions, and preserves deterministic dependency resolution under vcpkg manifest mode.
