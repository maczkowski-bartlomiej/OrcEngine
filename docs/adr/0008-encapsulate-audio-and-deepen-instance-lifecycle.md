# Encapsulate Audio Behind PIMPL and Deepen Sound Instance Lifecycle

Previously, `Audio.hpp` and `Bus.hpp` directly included `<fmod_studio.hpp>`, exposing third-party FMOD SDK types (`FMOD::Studio::System*`, `FMOD::Studio::Bank*`, `FMOD::Studio::Bus*`) into every consumer of `<Orc/Orc.hpp>`. Consequently, CMake was forced to link `FMOD` as a `PUBLIC` target dependency. Furthermore, sound playback was strictly fire-and-forget via `Audio::play()`, giving callers zero leverage to stop, pause, resume, loop, or parameterize individual sound instances without stopping an entire mixing bus. Finally, `Bus` was a shallow pass-through wrapper leaking `FMOD::Studio::System*` in its public `load()` method, and `Audio` hardcoded three specific buses with six repetitive getters.

We decided to encapsulate FMOD behind PIMPL, deepen sound playback with a generational handle, and establish dynamic bus mixing:
- **PIMPL Encapsulation**: All native FMOD types and system handles are encapsulated behind an opaque `UniquePtr<Audio::Impl> m_impl` defined in `Audio.cpp`. Engine public headers (`Audio.hpp`, `Bus.hpp`, `SoundHandle.hpp`) contain zero FMOD headers or types. `FMOD::Studio` and `FMOD::Core` are downgraded to `PRIVATE` dependencies in `CMakeLists.txt`.
- **Internal Audio Utility**: `fmodCall` is removed from public `Engine/Utility.hpp` and scoped to internal `AudioUtility.hpp` within the audio module, eliminating transitive FMOD header leaks across the engine.
- **Generational `SoundHandle`**: `Audio::play(path)` returns a lightweight, generational `SoundHandle` value type representing a live sound instance. Callers can control sounds (`stop()`, `pause()`, `resume()`, `setVolume()`, `setParameter()`) without managing raw memory or native pointers. Expired handles safely no-op.
- **Dual Playback Interface**: Callers use `playOneShot(path)` for transient fire-and-forget sounds (minimal overhead, immediate release) and `play(path) -> SoundHandle` for controllable sound instances.
- **Automatic Lifecycle Reaping**: `Audio::update()` polls active instance playback states once per frame, automatically releasing stopped instances (`FMOD_STUDIO_PLAYBACK_STOPPED`), recycling pool slots, and bumping generation counters.
- **Dynamic Bus Hierarchy**: Replaced the six hardcoded bus getters and leaky `Bus::load()` with dynamic bus querying via `Audio::getBus(busPath)`, returning an opaque `Bus` handle and supporting arbitrary mixing hierarchies alongside standard constants (`Bus::Master`, `Bus::SFX`, `Bus::Music`).
- **Fail-Fast Invariant**: Enforced immediate assertion crashes (`ORC_ASSERT`) on invalid bus lookups or corrupt audio states, adhering to the engine philosophy that invalid states should fail fast during development.
