# Decouple Layer Runtime and Input from Engine Singleton

`GameLayer` previously coupled directly to the global `Engine::get()` singleton by binding 7 engine subsystem references and window dimensions in its constructor, while `Keyboard` and `Mouse` static queries bypassed the layer interface to reach into native GLFW window handles. We decided to adopt constructor reference injection of `LayerContext&` for `GameLayer`, pass per-frame state via `const FrameContext&` to `onUpdate`, supply `Renderer&` directly to `onRender`, and decouple input polling into an event-driven `Input` subsystem. This eliminates ambient singleton dependencies, ensures layers and input state can be instantiated and tested in isolated headless test harnesses, and guarantees consistent input snapshots throughout frame updates.
