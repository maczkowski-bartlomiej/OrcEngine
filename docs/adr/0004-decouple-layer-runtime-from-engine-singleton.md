# Decouple Layer Runtime and Subsystems from Engine Singleton

`GameLayer`, `Gui`, `Font`, and static `Keyboard`/`Mouse` queries previously coupled directly to the global `Engine::get()` singleton. We decided to adopt constructor reference injection of `LayerContext&` for `GameLayer` (retaining `onUpdate(float deltaTime)` and `onRender()` while accessing subsystems via `m_layerContext`), decouple input polling into an event-driven `Input` subsystem inside `LayerContext`, inject `Window&` into `Gui`, scope `FT_Library` locally inside `Font::loadFromFile` (eliminating `FTLibrary`), and remove `Engine::get()` and individual subsystem getters from `Engine` in favor of `getLayerContext()`. This eliminates ambient singleton state across the entire engine while keeping layer lifecycle signatures concise.
